## 📋 Patrones Comunes

### Agregar una Nueva Feature

#### 1. Crear el Modelo
```bash
rails generate model Feature name:string property:references company:references
rails db:migrate
```

#### 2. Definir Asociaciones en `app/models/feature.rb`
```ruby
class Feature < ApplicationRecord
  belongs_to :property
  belongs_to :company
  
  validates :name, presence: true
  
  # Scope útil
  scope :active, -> { where(active: true) }
end
```

#### 3. Crear Controller
```bash
rails generate controller Features --skip-template-engine
```

#### 4. Crear Policy (Autorización)
```ruby
# app/policies/feature_policy.rb
class FeaturePolicy < ApplicationPolicy
  def index?
    user.admin?
  end

  def show?
    user.admin? || record.company.users.include?(user)
  end
end
```

#### 5. Implementar Controller
```ruby
# app/controllers/features_controller.rb
class FeaturesController < ApplicationController
  before_action :authenticate_user!
  before_action :set_feature, only: [:show, :edit, :update, :destroy]
  before_action :authorize_feature, only: [:show, :edit, :update, :destroy]

  def index
    @features = policy_scope(Feature)
  end

  def show
  end

  def new
    @feature = Feature.new
  end

  def create
    @feature = Feature.new(feature_params)
    @feature.company = current_user.company

    if @feature.save
      redirect_to @feature, notice: "Feature creado"
    else
      render :new
    end
  end

  private

  def feature_params
    params.require(:feature).permit(:name, :property_id)
  end

  def set_feature
    @feature = Feature.find(params[:id])
  end

  def authorize_feature
    authorize @feature
  end
end
```

#### 6. Rutas
```ruby
# config/routes.rb
resources :features
```

#### 7. Tests
```ruby
# test/models/feature_test.rb
test "feature creado con nombre válido" do
  feature = Feature.new(name: "Pool", property: properties(:one))
  assert feature.valid?
end

# test/controllers/features_controller_test.rb
test "solo admin puede ver features" do
  get features_url
  assert_response :redirect  # No autenticado
end
```

```ruby

```

### Crear un Background Job

```bash
rails generate job SendPaymentReminder
```

```ruby
# app/jobs/send_payment_reminder_job.rb
class SendPaymentReminderJob < ApplicationJob
  queue_as :default

  def perform(charge_id)
    charge = Charge.find(charge_id)
    
    if charge.pending?
      ChargeMailer.payment_reminder(charge).deliver_later
      charge.update(reminder_sent_at: Time.now)
    end
  end
end
```

#### Usarlo
```ruby
# Enqueue el job
SendPaymentReminderJob.set(wait: 5.days).perform_later(charge.id)
```

#### En Config
```ruby
# config/recurring.yml
payment_reminders:
  cron: '0 9 * * *'  # Cada día a las 9 AM
  job: 'SendPaymentReminderJob'
```

## 🔒 Trabajar con Autorización (Pundit)

### Crear Una Policy Nueva
```ruby
# app/policies/property_policy.rb
class PropertyPolicy < ApplicationPolicy
  def index?
    true  # Todos pueden listar
  end

  def show?
    user.admin? || record.company.users.include?(user)
  end

  def create?
    user.admin? || user.company_manager?
  end

  def update?
    show?
  end

  def destroy?
    user.admin?
  end
end
```

### Scope (Filtrar Recursos)
```ruby
class PropertyPolicy < ApplicationPolicy
  class Scope < ApplicationPolicy::Scope
    def resolve
      if user.admin?
        scope.all
      else
        # Solo propiedades de su empresa
        scope.where(company_id: user.company_ids)
      end
    end
  end
end
```

### En Controller
```ruby
class PropertiesController < ApplicationController
  def index
    @properties = policy_scope(Property)  # Filtra automáticamente
  end

  def show
    authorize @property  # Verifica show? en policy
  end
end
```

## 🚀 Deployment Checklist

Antes de hacer deploy a production:

- [ ] Tests pasando: `rails test`
- [ ] No hay warnings de Rubocop: `bin/rubocop`
- [ ] Brakeman sin issues críticos: `bin/brakeman`
- [ ] Migraciones preparadas y reversibles
- [ ] Secrets en `config/credentials.yml.enc` (no en código)
- [ ] Assets compilados: `rails assets:precompile`
- [ ] Dockerfile actualizado si cambios en dependencies
- [ ] Update README.md si hay cambios en setup

```bash
kamal setup   # Primera vez

kamal logs --follow

kamal rollback
```

## 📊 Query Performance

### Identifica N+1 Queries
```ruby
# EN development.log o console, busca queries repetidas

# MAL:
Property.all.each { |p| p.contracts.count }  # 1 + N queries

# BIEN:
Property.includes(:contracts).map { |p| p.contracts.size }
# O
Property.left_joins(:contracts)
         .select('properties.*, COUNT(contracts.id) as contracts_count')
         .group('properties.id')
```

### Agrega Índices
```bash
rails generate migration AddIndexToContracts property_id:index
```

```ruby
class AddIndexToContracts < ActiveRecord::Migration[8.1]
  def change
    add_index :contracts, :property_id
    add_index :contracts, :tenant_id
    add_index :contracts, [:property_id, :tenant_id], unique: true
  end
end
```

## 🎨 Estilo y Convenciones

### Nombres de Variables y Métodos
```ruby
# Models (singular, CamelCase)
class RentalProperty < ApplicationRecord
end

# Controllers (plural, CamelCase + Controller)
class RentalPropertiesController
end

# Variables (snake_case)
@rental_property = RentalProperty.first
first_rental_property = @properties.first

# Métodos booleanos (? al final)
def active?
  status == 'active'
end

# Métodos destructivos (! al final)
def save!
  save || raise StandardError, "Failed to save"
end
```

### Orden en Modelo
```ruby
class Property < ApplicationRecord
  # 1. Associations
  belongs_to :company
  has_many :contracts
  
  # 2. Validations
  validates :name, presence: true
  
  # 3. Callbacks
  before_save :normalize_data
  
  # 4. Scopes
  scope :active, -> { where(active: true) }
  
  # 5. Métodos públicos
  def monthly_revenue
    contracts.map(&:rent_amount).sum
  end
  
  # 6. Métodos privados
  private
  
  def normalize_data
    self.name = name.strip
  end
end
```

## 🛑 Anti-Patrones a Evitar

### ❌ NUNCA
```ruby
# Skipear autorización
Property.find(params[:id])  # Sin authorize!

# Hardcodear secrets
stripe_key = "sk_live_..."  # En código

# N+1 Queries
User.all.each { |u| puts u.company.name }

# Lógica en views
<%= if user.admin? %>...  # Usa helpers

# Migraciones irreversibles
def change
  drop_table :users  # ¿Cómo rollback?
end

# Controllers gordos
def create
  # 200 líneas de lógica...
end
```

### ✅ SIEMPRE
```ruby
# Autorizar
authorize @property

# Usar credentials
Stripe.api_key = Rails.application.credentials.stripe_secret_key

# Eager load
Property.includes(:company).all

# Helpers para lógica
<%= render 'admin_section' if user_admin?(current_user) %>

# Migraciones reversibles
def change
  create_table :audit_logs do |t|
    # ...
  end
end

# Servicios para lógica compleja
class PropertySetupService
  def initialize(property)
    @property = property
  end
  
  def call
    # 200 líneas de setup lógico
  end
end
```

## 🆘 Troubleshooting Común

| Problema | Solución |
|----------|----------|
| ActiveRecord::RecordNotFound | `Property.find(id)` con id inválido → Usa `.find_by(id: id)` |
| Pundit::NotAuthorizedError | Policy no permitió acción → Revisa policy y user.role |
| N+1 Query en logs | Add `.includes()` o `.preload()` |
| Sass compilation error | `npm run build:css` manualmente |
| Devise sign_in no funciona en tests | Usa `sign_in users(:admin)` desde test_helper |
| Capybara click_link no encuentra | Usa exact_text: `click_link "Exact Text"` |
